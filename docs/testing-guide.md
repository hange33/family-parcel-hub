# 后台同步与到件通知 - 真机测试指南

## 🚀 快速测试步骤

### 1. 启动 App
```bash
flutter run
```

### 2. 进入测试工具

1. 打开 App 主页
2. 点击右上角设置图标
3. 找到「数据管理」部分
4. 点击 **「后台同步测试工具」**（橙色图标）

### 3. 测试通知功能

按照以下顺序测试：

#### 测试 A：直接测试通知（最快）
1. 点击 **「4. 直接测试通知」**
2. 查看通知栏是否收到通知
3. 通知内容：「快递到了！圆通 取件码：9999」

✅ **预期结果**：立即收到通知

---

#### 测试 B：模拟完整流程
1. 点击 **「1. 创建在途包裹」**
   - 查看主页是否出现测试包裹
   - 状态应为「在途中」

2. 点击 **「2. 模拟包裹到达（触发通知）」**
   - 主页包裹状态变为「待取件」
   - 应显示取件码
   - **立即收到通知**

3. 点击 **「5. 查看包裹统计」**
   - 查看日志中的统计信息
   - 确认同步间隔建议

4. 点击 **「6. 清理测试包裹」**
   - 清除所有测试数据

✅ **预期结果**：
- 包裹状态正确变化
- 收到到件通知
- 主页卡片显示正常

---

#### 测试 C：后台同步间隔（需要时间）
1. 点击 **「3. 创建派送中包裹（15分钟高频）」**
2. 查看日志确认：「⏱️ 后台同步间隔应为 15 分钟」
3. 按 **Home 键**，App 进入后台
4. 查看 Android Studio 或 adb logcat 日志：
   ```bash
   adb logcat | grep "BackgroundSyncService"
   ```
5. 观察日志输出：
   - `[BackgroundSyncService] Starting background sync...`
   - `[BackgroundSyncService] Next sync interval: 15 minutes`
   - `[BackgroundSyncService] Performing sync...`

6. 切回 App，查看日志确认后台同步已暂停：
   - `[BackgroundSyncService] Pausing background sync...`

✅ **预期结果**：
- 后台时启动定时同步
- 前台时暂停同步
- 同步间隔根据包裹状态调整

## 📱 通知权限检查

如果没有收到通知，请检查：

### Android 系统设置
1. 打开 **设置 → 应用 → pickup_app**
2. 检查 **通知权限** 是否开启
3. 检查 **后台运行权限**（可选）

### 代码内检查（调试用）
在 `NotificationAdapter.initialize()` 添加权限检查：
```dart
final permission = await _plugin
    .resolvePlatformSpecificImplementation<
        AndroidFlutterLocalNotificationsPlugin>()
    ?.requestNotificationsPermission();
print('Notification permission: $permission');
```

## 🐛 调试日志

### 查看后台同步日志
```bash
# 过滤后台同步服务日志
adb logcat | grep "BackgroundSyncService"

# 查看通知相关日志
adb logcat | grep "NOTIFICATION"

# 查看包裹提供者日志
adb logcat | grep "PackageListNotifier"
```

### 关键日志说明

| 日志内容 | 含义 |
|---------|------|
| `Lifecycle changed: paused` | App 进入后台 |
| `Starting background sync...` | 启动后台定时同步 |
| `Next sync interval: 15 minutes` | 下次同步间隔 |
| `Performing sync...` | 正在执行同步 |
| `Sync completed: N packages` | 同步完成，获取 N 个包裹 |
| `Pausing background sync...` | 暂停后台同步 |
| `arrived, triggering notification` | 检测到包裹到达，触发通知 |

## 🔧 常见问题

### Q1: 没有收到通知
**原因**：
- 通知权限未开启
- Android 13+ 需要动态申请权限
- 通知被系统拦截

**解决方法**：
1. 检查系统设置中的通知权限
2. 在代码中添加权限请求（见上文）
3. 使用「4. 直接测试通知」排除其他因素

### Q2: 后台同步不执行
**原因**：
- App 被系统杀掉（这是预期行为）
- 生命周期监听未触发
- 定时器被取消

**解决方法**：
1. 确认 App 在后台运行（未被完全杀掉）
2. 查看 logcat 日志确认生命周期变化
3. 使用「3. 创建派送中包裹」触发高频同步，更容易观察

### Q3: 同步间隔不正确
**原因**：
- 包裹状态判断逻辑问题
- 多个不同状态包裹时取最高优先级

**解决方法**：
1. 使用「5. 查看包裹统计」确认当前包裹状态
2. 查看日志中的间隔计算过程
3. 清理测试包裹后重新测试

### Q4: 测试包裹不显示
**原因**：
- 包裹被过滤器排除
- 状态机判断问题

**解决方法**：
1. 检查主页是否有过滤条件
2. 查看 `PackageListNotifier` 日志
3. 使用「6. 清理测试包裹」后重试
