# 固定签名密钥库

**为什么有这个目录**：CI 每次构建都会现场生成 debug keystore，密钥随机 →
每个包签名不同 → 安装时必须先卸载 → App 数据（含平台登录态）全丢。
所以这里放一把**固定**的自签名密钥，所有构建共用，新包可以直接覆盖安装。

| 文件 | 说明 |
|---|---|
| `hub-release.p12` | PKCS12 密钥库（RSA 2048，自签，有效期 25 年） |
| `keystore.properties` | 口令与别名（同一把口令，仅本私有仓库可见） |

`android/app/build.gradle.kts` 会自动读取：存在则用 `hubRelease` 签名，不存在才退回 debug。

## 风险与边界

- 私钥进仓库（私有库）是自用工具的常见取舍：仓库一旦泄露，别人可以签出"看起来是你"的更新。
- 不要把这个仓库改成公开；不要把这套密钥用于任何上架分发。
- 换机/重装后想继续覆盖安装，必须保留这两个文件。

## 首次迁移

之前的包是 debug 签名，与本密钥不同 → **这一次仍需卸载重装**。
从本版起，后续可直接覆盖安装，登录态与数据保留。
